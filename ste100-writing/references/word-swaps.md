# 字詞替換清單

**這不是官方 STE 字典。** 這是本 skill 用的「常見難字 → 簡單字」清單。大部分方向和 STE 字典一致，但在 strict 模式下不能宣稱「符合官方字典」。`scripts/ste_check.py` 內建同一份清單；修改這裡時，記得一起改腳本裡的 `SWAPS`。

## 常被小抄寫錯的字（依官方標準查核過）

| 字 | 正確情況 |
|---|---|
| approximately | **是核准字**（副詞）。有些小抄說要改成 "about"，這是錯的。 |
| about | 只核准「關於（concerned with）」的意思。不要用來表示「大約」："Drain about 2 liters" ✗ → "Drain approximately 2 liters" ✓ |
| test | 只核准當**名詞**。"Test the pump" ✗ → "Do a test of the pump" ✓ |
| ensure | 非核准。改用 "make sure"。 |
| in order to | 字典裡沒有這個詞條，但改成 "to" 是好建議。 |
| passive voice | 描述寫作中，只有「不知道動作者」時才可以用被動，不是「必要時」就可以。 |
| noun cluster | 新版術語叫 "multi-word noun"；"technical name" 新版叫 "technical noun"。 |

## 動詞

| 避免 | 改用 |
|---|---|
| utilize, utilise | use |
| ensure | make sure |
| commence, initiate | start |
| terminate | stop, end |
| obtain, acquire | get |
| assist, facilitate | help |
| perform, accomplish, execute (a task) | do（程式則用 run） |
| require(s) | must have, is necessary, need |
| indicate, demonstrate | show |
| modify | change |
| attempt, endeavor | try |
| determine | find, decide（看意思） |
| eliminate | remove |
| retain | keep |
| reside (in) | be (in) |
| inform, notify | tell |
| possess | have |
| leverage | use |
| purchase | buy |
| make use of | use |
| is able to, has the ability to, it is possible to | can |

## 片語動詞（意思太多，換成單一意思的動詞）

| 避免 | 改用 |
|---|---|
| set up | install, configure, make（寫清楚是哪個） |
| carry out | do |
| figure out, find out | find |
| look into | examine |
| come up with | make, find |
| go through | read, examine |
| point out | show, tell |
| deal with | 依情況寫 repair / correct / process |

## 連接詞與片語

| 避免 | 改用 |
|---|---|
| prior to | before |
| subsequent to, subsequently | after, then |
| due to the fact that, owing to the fact that | because |
| in the event that | if |
| in order to | to |
| at this point in time, at the present time | now |
| a number of | some, many, 或直接寫數字 |
| a variety of | different, many |
| numerous | many |
| sufficient | enough |
| additionally, in addition | also |
| with regard to, with respect to, in terms of, regarding | about |
| functionality | function |
